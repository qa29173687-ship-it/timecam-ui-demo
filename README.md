# 時間相機 介面 DEMO

這是給「時間相機」看的**可點介面示範頁**，不是已安裝的 App，也不會真的拍照或上傳。

- 畫面依參考的時間浮水印相機重新排過：上方白列、滿版預覽、左下大時間浮水印、右緣焦距與快捷鈕、下方快門與「本機照片／範本」
- 時間會依「台北時間」即時更新，並蓋在預覽上（示範用）
- 閃光燈、前後鏡頭、照片／影片、範本、編輯浮水印、定位都可以點
- 「設定」裡有「自動上傳 Google 雲端」的示範選項（開／關、上傳時間、只在 Wi‑Fi、只在充電、資料夾名稱、連結帳號）。**不會真的連結 Google，也不會上傳檔案**
- 資料只存在這個瀏覽器的 localStorage
